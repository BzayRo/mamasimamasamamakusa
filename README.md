# 🛒 Catálogo Dark World - Filtros Avanzados

Proyecto de práctica escolar para demostrar el uso de filtros condicionales, ordenamiento y límites en bases de datos en la nube.

## 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5, CSS3 (Diseño retro inspirado en *Deltarune* con tipografía VT323) y JavaScript (Vanilla).
* **Backend y Base de Datos:** Supabase (PostgreSQL), utilizando consultas con `.eq()`, `.order()` y `.limit()`.

## 📁 Estructura del proyecto
* `index.html` — Estructura de la interfaz de usuario.
* `style.css` — Estilos visuales con temática de videojuegos retro.
* `main.js` — Lógica de conexión a la base de datos y ejecución de consultas avanzadas.

## 🚀 Cómo ejecutar el proyecto
1. Descarga o clona la carpeta del proyecto en tu computadora.
2. Abre el archivo `index.html` en cualquier navegador web moderno (como Chrome, Edge o Firefox).
3. Haz clic en el botón de consulta para ver los productos filtrados y ordenados.
